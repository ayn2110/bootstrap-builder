# Bootstrap Builder Game Project Prompt

## Project Goal
Create an interactive game similar to CSS Diner/Flexbox Froggy to teach Bootstrap 5 concepts, specifically the Grid System.

## Core Features
1.  **Single Page Application**: `bootstrap-builder-game.html` contains all logic.
2.  **Level System**: 25 levels covering Grid, Spacing, RWD, and Images.
3.  **Interactive Editor**: Users type class names to see real-time updates.
4.  **Visual Feedback**: Preview area updates instantly; "Check Answer" validates inputs.
5.  **Educational Aids**:
    *   Hints for each level.
    *   **CSS Supplement**: Shows the underlying CSS rules for the Bootstrap classes used.
    *   Reference images and links to official docs.

## File Structure
- `bootstrap-builder-game.html`: Main entry point.
- `MAIN.md`: Design document and curriculum.
- `styles.css`: Custom styles for the game interface.

## Current Status
