# 🎮 Bootstrap Builder - 互動學習遊戲

將 Bootstrap 核心概念設計成類似 CSS Diner（或 Flexbox Froggy）的遊戲，提高學生的學習興趣和實作記憶的教材。

## 📋 專案概述

**Bootstrap Builder** 是一個互動式網頁遊戲，幫助學生通過實作練習來學習 Bootstrap 5 的網格系統和核心概念。學生需要撰寫正確的 Bootstrap Class，將畫面右側的區塊精準地移動到指定目標區域。

## 🎯 遊戲目標

- 學習 Bootstrap 網格系統（Grid System）的基本概念
- 掌握響應式網頁設計（RWD）的實作方法
- 透過實作強化 Bootstrap Class 的記憶
- 建立正確的佈局思維方式

## 🛠️ 使用技術

- **HTML5** - 網頁結構
- **CSS3** - 樣式設計
- **JavaScript ES6** - 交互邏輯
- **Bootstrap 5.3.8** - UI 框架和網格系統

## 📚 遊戲關卡設計（共 21 關）

### 主題一：網格系統與排版基礎（1-1 ~ 1-9）

| 關卡 | 標題 | Bootstrap Class | 目標 |
|------|------|-----------------|------|
| 1-1 | 容器邊界 | `.container` | 將內容放置於響應式容器中 |
| 1-2 | 全寬內容 | `.container-fluid` | 實現橫幅廣告滿版效果 |
| 1-3 | 啟動分欄 | `.row` | 創建水平分欄區塊 |
| 1-4 | 自動填充 | `.col` | 單一元件自動填充空間 |
| 1-5 | 雙欄對等 | `.col` x2 | 兩個元素等寬排列 |
| 1-6 | 三欄佈局 | `.col` x3 | 三個元素等寬排列 |
| 1-7 | 五等份挑戰 | `.col` x5 | 五個元素等寬排列 |
| 1-8 | 內容側邊欄 | `.col-8`, `.col-4` | 經典 8+4 佈局 |
| 1-9 | 管理區塊 | `.col-9`, `.col-3` | 管理後台 9+3 佈局 |

### 主題二：間距與對齊（2-1 ~ 2-7）

| 關卡 | 標題 | Bootstrap Class | 目標 |
|------|------|-----------------|------|
| 2-1 | 水平居中 | `.mx-auto` | 固定寬度區塊水平置中 |
| 2-2 | 頂部留白 | `.pt-5` | 調整上內邊距 |
| 2-3 | 底部外擴 | `.mb-4` | 調整下外邊距 |
| 2-4 | 文字置中 | `.text-center` | 文字對齊置中 |
| 2-5 | 垂直對齊 | `.align-items-center` | Row 內元素垂直居中 |
| 2-6 | 間距微調 | `.mt-3`, `.px-4` | 組合間距 Class |
| 2-7 | 均勻分佈 | `.justify-content-around` | 水平均勻分佈 |

### 主題三：響應式設計（3-1 ~ 3-5）

| 關卡 | 標題 | Bootstrap Class | 目標 |
|------|------|-----------------|------|
| 3-1 | 中斷點分割 | `.col-12`, `.col-md-6` | RWD 桌面並排/手機堆疊 |
| 3-2 | 順序反轉 | `.order-first`, `.order-md-last` | RWD 不同斷點改變順序 |
| 3-3 | 欄位位移 | `.offset-3` | 使用 offset 實現置中 |
| 3-4 | 消除間距 | `.g-0` | 移除 Gutter 間距 |
| 3-5 | 特定隱藏 | `.d-none`, `.d-lg-block` | RWD 條件顯示/隱藏 |

## 🎮 遊戲功能

### 核心機制
- ✅ **代碼編輯器** - 学生輸入 Bootstrap Class 的文本框
- ✅ **即時預覽** - 右側實時顯示代碼的效果
- ✅ **答案驗證** - 檢查學生輸入是否正確
- ✅ **進度追蹤** - 進度條和關卡計數
- ✅ **參考設計** - 預留區域放置設計參考圖片
- ✅ **提示系統** - 每個關卡提供學習提示

### 用戶交互
- 輸入 Bootstrap Class
- 即時看到預覽效果
- 點擊「檢查答案」驗證
- 點擊「重置」清空輸入
- 完成後點擊「下一關」進入下一關卡
- 全部完成顯示成就頁面

## 🚀 快速開始

### 本地運行
1. 將文件放在 Web 服務器的根目錄（如 XAMPP 的 `htdocs`）
2. 用瀏覽器開啟 `bootstrap-builder-game.html`
3. 開始遊戲！

### 在線運行
1. 推送到 GitHub Pages
2. 訪問：`https://[your-username].github.io/bootstrap-builder`
